# Cartera superpuesta

Se recuperó la composición de cartera con un máximo de tres pases visibles. Cada pase muestra la etiqueta; el seleccionado muestra el nombre y tipo. Los colores se derivan de la tarjeta y se oscurecen con carbón, conservando la paleta de marca en los controles. Bordes finos, sombras y una transición de posición de 460 ms aportan profundidad sin añadir información ficticia bancaria.

Se puede tocar la cabecera expuesta, deslizar horizontalmente o usar las flechas. Con más de tres tarjetas las flechas recorren toda la colección. La navegación no cambia la tarjeta activa almacenada. El detalle editable sigue debajo. Movimiento reducido desactiva las transiciones y el tamaño de las tarjetas crece con la escala del texto.

Referencia general consultada: https://www.banamex.com/personas/banca-digital/app-banamex. Diseño propio para Reson; no se importaron recursos ni marcas del banco.

Validación: 55 pruebas funcionales, navegación por cabecera y filtros, capturas móviles en claro/oscuro. No hay cambios en Firebase ni en el contenido de las tarjetas.
